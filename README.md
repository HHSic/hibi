# 눈쉼

눈과 몸을 위한 휴식 리마인더 위젯 (Windows).

바탕화면에 상시 떠 있는 유리 카드가 다음 알림까지 남은 시간을 보여주고,
때가 되면 화면 전체에 조용한 휴식 화면을 띄운다.

## 기능

- **알림 종류 8종** — 눈 휴식 · 인공눈물 · 자세 교정 · 물 마시기 · 스트레칭 · 일어서기 · 손목 풀기 · 심호흡
  각각 켜고 끄고, 주기와 길이를 따로 조절한다.
- **겹치는 알림 묶기** — 비슷한 시각에 올 알림은 한 번의 휴식으로 묶어 방해 횟수를 줄인다.
  (각 알림 주기의 35%, 최대 15분 안에 올 것을 함께 당겨 처리)
- **위젯** — 배경이 진행률로 채워지고, 색은 다음 알림 종류를 따른다.
  클릭하면 모든 알림의 남은 시간이 보이고, 끌어서 옮기고 우하단 그립으로 크기를 바꾼다.
  176×84 ~ 460×220 범위에서 크기대별로 레이아웃이 바뀐다.
- **휴식 화면** — 휴식 직전 바탕화면을 캡처해 흐린 배경으로 쓴다. 짧은 알림은 안내 문구,
  묶인 알림이나 긴 휴식은 체크리스트. 다 했으면 남은 시간을 기다리지 않고 끝낼 수 있다.
- **자리 비움 감지** — 일정 시간 입력이 없으면 카운트다운을 멈춘다.
- 트레이 상주, 시작 시 자동 실행(설정에서 켜기).

## 개발

```bash
npm install
npm start
```

개발용 환경변수 `NUNS_DEV`로 창을 바로 띄울 수 있다.

```bash
# 설정 창과 휴식 화면을 실행 직후 띄운다
$env:NUNS_DEV="settings,break"; npm start
```

## 배포용 빌드

```bash
npm run dist
```

`dist/` 에 두 가지가 나온다.

| 파일 | 용도 |
|---|---|
| `nunsseom-0.1.0-x64.exe` | NSIS 설치 프로그램 (설치 위치 선택 가능, 바탕화면·시작메뉴 바로가기) |
| `nunsseom-0.1.0-portable.exe` | 설치 없이 바로 실행 (USB 등) |

폴더만 만들어 확인하려면 `npm run pack`.

### 서명되지 않은 빌드에 대해

코드 서명 인증서가 없으면 Windows SmartScreen이 "알 수 없는 발행자" 경고를 띄운다.
받는 사람은 **추가 정보 → 실행**을 눌러야 한다. 없애려면 코드 서명 인증서가 필요하고,
평판이 쌓이기 전까지는 OV 인증서로도 경고가 남을 수 있다.

### 설정 저장 위치

`%APPDATA%\눈쉼\nunsseom.json`
(Electron이 `productName`을 폴더 이름으로 쓴다. 제거해도 이 파일은 남는다.)

## 구조

```
src/
  main.js       메인 프로세스 — 창 생성, 트레이, IPC, 틱 루프
  reminders.js  알림 종류 정의와 스케줄러 (묶음 로직)
  store.js      설정·통계·위젯 위치 저장 (userData JSON)
  glass.js      유리 창 정책과 여백 상수
  preload.js    contextBridge API
renderer/
  widget.html   위젯
  overlay.html  휴식 화면
  settings.html 설정
  icons.js      벡터 글리프
assets/
  tray.png      트레이 아이콘
  font/         Pretendard woff2 (쓰는 6개 두께만)
build/
  icon.ico      앱 아이콘
```

### 유리 효과에 대한 메모

Windows에서 **큰 라운드 + 매끈한 코너**와 **실시간 배경 블러**는 동시에 가질 수 없다.
실측으로 확인한 내용은 `src/glass.js` 주석에 남겨두었다. 이 프로젝트는 라운드 품질을 택해
투명 창 + CSS `border-radius`를 쓰고, 유리감은 틴트(`--scrim`) + 내부 하이라이트 + 그림자로 만든다.
휴식 화면만은 전체화면이라 캡처한 바탕화면을 흐리게 깔아 진짜 블러를 쓴다.
